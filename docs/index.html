Getting Started

Prerequisites

  • Python 3.10+ and pip
  • Node.js 18+ and npm
  • Git

1. Clone the Repository

$ git clone https://github.com/Harshill1912/LuxeStay-assignment.git
$ cd LuxeStay-assignment

2. Backend Setup

$ cd backend
$ pip install -r requirements.txt

# Create .env file with:
DATABASE_URL=sqlite:///./luxestay.db
SECRET_KEY=your_secret_key
GEMINI_API_KEY=your_gemini_api_key
LLM_MODEL=gemini-flash-latest

# Seed the database
$ python seed.py

# Start the server
$ uvicorn app.main:app --reload --port 8000

3. Frontend Setup

$ cd frontend
$ npm install

# Create .env.local with:
NEXT_PUBLIC_API_URL=http://localhost:8000

# Start the dev server
$ npm run dev

4. Open in Browser

Frontend → http://localhost:3000
Backend API → http://localhost:8000/docs

Deployment

Backend — Render

  • Service: Web Service (Python)
  • Build Command: pip install -r requirements.txt
  • Start Command: uvicorn app.main:app --host 0.0.0.0 --port $PORT
  • Root Directory: backend/
  • Environment: DATABASE_URL, SECRET_KEY, GEMINI_API_KEY

Frontend — Vercel

  • Framework: Next.js
  • Root Directory: frontend/
  • Environment: NEXT_PUBLIC_API_URL=https://luxestay-assignment.onrender.com

Database — Render PostgreSQL

  • Auto-seeded on first startup with demo users and room inventory
  • 12 luxury rooms across 4 categories (Suites, Villas, Executive, Cabanas)

Key API Endpoints

POST /api/auth/signup # Register new user
POST /api/auth/login # Login & get JWT token
GET /api/rooms # List all rooms
POST /api/bookings # Create booking request
GET /api/bookings # Get user's bookings
PATCH /api/bookings/{id}/status # Approve/Reject (admin)
POST /api/bookings/{id}/pay # Process 30% deposit
POST /api/chat # AI Concierge chat
GET /api/admin/stats # Dashboard metrics (admin)
